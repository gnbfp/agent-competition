# RunWise AI V3.1 配色与动效调整

基于 V3.0，针对训练报告中的浅色总结卡与深色主题的断层进行界面改版。

## 对比

- 原版：总结卡在暗色主题中使用接近白色的浅蓝紫，视觉断层明显；动画色差不大。
- 新版：总结卡采用深蓝—靛紫—青蓝流动渐变，正文使用白色；训练建议是紫—青蓝强调色；日常指标卡分别采用蓝、紫、蓝绿与暖灰紫。
- 保留墨绿主背景作为视觉基底，不再用绿色填满所有模块。

## 动效

CSS 动画 `rw31-spectrum` 改变真实背景位置，`rw31-aurora` 移动柔和光晕，周期约 9–15 秒；不是视频或静态图片。右上角“◈”按钮可暂停，操作系统减少动画和打印模式下自动停用。

## 不变的行为

本次为视觉层修改；CSV 解析、R15 疼痛复核、训练计划计算、专业指标和风险规则均未更改。
