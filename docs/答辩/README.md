## 三个必答问题（先想好）

1. **这和市面上的跑步 App 有什么区别？** —— 它们给计划不给依据；我们每条结论挂 `rule_id` 和文献。
2. **你怎么证明它是对的？** —— L1 回测提前 3 天预警真实事件、L2 三法一致性 <5%、L3 脏数据检出 ≥90%、L4 5 名跑友 4 周对照、L5 体育老师盲评。
3. **真有人用吗？** —— 第一个用户是队长本人；跑友群 5 人试用；零硬件成本。

## 演示纪律

- 演示只用**预置数据**，断网也要能跑（起 `mock_api` + 本地页面）。
- 每个数字都能点开看到依据；点不开的就别放。
- 不许念稿式背 PPT，每页只讲一个结论 + 一个证据。
