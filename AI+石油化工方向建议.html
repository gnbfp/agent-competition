AI＋石油化工方向建议（赛道三）

你的问题：想做 AI＋石油化工。
结论先行：主推「化工过程 HAZOP 分析助手」——把化工安全分析的标准方法（IEC 61882）做成能对话、能自查、能出工作表的智能体。它是石油化工里少数不依赖企业私有数据、又同时踩中常大两个最强学科的方向。

零、先认清这个方向真正的障碍

石油化工的知识不缺，缺的是数据：真实装置的 DCS 数据、原油评价数据（assay）、催化剂配方、操作经验，全是企业私有。学生队拿不到，也不该拿。

所以选题的第一道筛子不是"哪个题目高级"，而是：

这个任务，能不能只靠"工艺知识 + 公开规范 + 文本描述"就做出有专业价值的结果？

按这条一划，一堆看起来诱人的题目直接出局：

看起来很好为什么做不了
炼厂全流程优化需要企业级流程模拟软件与真实数据
催化剂配方/反应条件优化数据私有，且需要实验验证
管道泄漏检测真实泄漏数据私有（和示功图同一个坑）
装置故障预测没有历史 DCS 数据，做出来是自欺欺人

留下的，是规则密集、输入可文本化、结果可对照检查的任务。HAZOP 正是其中最典型的一个。

一、主推方向：化工过程 HAZOP 分析助手

HAZOP 是什么（一句话讲给评委听）

危险与可操作性分析：把工艺过程拆成若干"节点"，对每个节点用引导词 × 工艺参数逐条追问"如果这里流量没了会怎样、压力过高会怎样"，系统性地找出偏差、原因、后果和现有防护。它是化工安全分析的国际标准方法（IEC 61882），也是新建/改扩建装置必须做的合规工作。

痛点是真的

  • 一次完整 HAZOP 要组织工艺、设备、仪表、安全多专业专家开会，几天到几周
  • 中小企业、教学场景做不起，常常照抄模板、漏掉偏差——而事故往往就出在被漏掉的那一条
  • 分析质量高度依赖主持人经验，新人无从下手

输入 / 输出

内容
输入工艺流程描述：节点划分、设备与物料、操作条件（温度/压力/流量/液位）、控制回路、已有安全设施（报警、联锁、泄放、围堰）
输出HAZOP 工作表：节点 × 引导词 × 参数的偏差表，每行含 原因 / 后果 / 现有防护 / 建议措施 / 风险等级 / 信息缺口标注

规则内核（这是作品的核心资产）

引导词 × 参数矩阵是 HAZOP 的形式化骨架：

引导词含义常见参数组合
无 / 空白（NO）完全没有流量无、冷却水中断
过多（MORE）超过设计值压力过高、温度过高、液位过高
过少（LESS）低于设计值流量过低、液位过低
部分（PART OF）组分缺失原料配比异常
相反（REVERSE）方向相反逆流、倒灌
伴随（AS WELL AS）额外混入杂质、空气、水进入
其他（OTHER THAN）完全不同的工况开停车、异常工况

每个"引导词×参数"格子里，再按固定推理链展开：

偏差 → 可能原因（设备/仪表/操作/外部） → 后果（人员/设备/环境/停产） → 现有防护层（BPCS→报警→SIS 联锁→泄放/围堰→应急） → 建议措施 → 风险等级

这条推理链就是你要写成规则表的东西，字段建议：

rule_id / 节点类型 / 引导词 / 参数 / 偏差 / 原因类别 / 后果类型 / 防护层要求 / 依据（标准条款/工程实践）/ 需补充信息

规则表示例行（精馏塔回流罐，参数=液位，引导词=无）：

项内容
偏差回流罐液位过低/无液
原因回流泵抽空、液位计失灵、塔顶冷凝器冷却不足、回流量控制阀卡开
后果回流中断 → 塔顶产品不合格；泵干转损坏；严重时塔压波动
现有防护液位低报警、回流泵联锁停、塔顶温度高报警
建议增设液位低低联锁、液位计冗余（双法兰+雷达）、泵最小流量保护
依据IEC 61882 分析流程；GB/T 21109 安全仪表系统功能安全思路

AI 在哪、规则在哪

环节谁做
把自然语言工艺描述拆成节点并识别设备/物料/参数LLM ＋ 结构化模板
生成 7×N 偏差矩阵规则引擎（确定性，不允许漏项）
逐条推理原因/后果/防护规则库为主，LLM 补充表述与同义扩展
判断"这条分析成立吗"规则引擎 ＋ 证据检索
识别信息缺口并追问（"这台的泄放去哪？有无联锁？"）Agent 循环
出表后自查"矩阵覆盖度是否 100%"Agent 自校验

关键设计：偏差矩阵必须是穷举生成的，不允许 AI 自由发挥。这一条既是质量保证，也是答辩时最好讲的点——"我们不靠模型想，我们靠矩阵逼它不漏。"

Agent 形态（为什么它是智能体而不是表格工具）

主循环：解析工艺 → 划分节点 → 穷举偏差矩阵 → 逐格分析 → 覆盖度自查（发现空格打回重做或追问）→ 缺信息追问 → 输出工作表

必须可见的三处智能体行为：

  1. 主动追问：工艺描述里没写"反应器有无温度高联锁"，它不会默认"有"，而是标注"防护层未知，需确认"并追问
  2. 换路重试：某条偏差查不到依据时，先查同义表述、再查上位标准，都失败才标"无依据"
  3. 自校验打回：生成后统计"42 格中已分析/待确认/无法判定"的数量，覆盖度不足就重跑，不达标不给结论

怎么验证（这是它能赢的关键）

  1. 公开案例回放：用教材/公开的 HAZOP 报告（储罐区、换热器、精馏塔这类经典案例）做对照，算偏差覆盖率与原因命中率
  2. 专家评审：请化工/安全方向老师评 10 个节点，记录"漏掉的分析"并补进规则库——修正记录就是答辩材料
  3. 信息缺口测试：故意给一份缺联锁、缺泄放去向的工艺描述，看它是否追问而不是编造
  4. 一致性测试：同一工艺描述跑两次，结果应稳定（规则引擎保证确定性）

第一版边界（六周能做完）

  • 3 类典型节点：储罐区、换热器、精馏塔（不做全流程）
  • 7 个引导词 × 4 个参数（流量/压力/温度/液位）
  • 只出"分析与待确认项"，不判定装置是否安全（责任边界）
  • P&ID 不做图像识别，v1 用文本化工艺描述或表格输入
  • 规则库 40–60 条，每条带依据

为什么这个方向最稳

  • 踩中常大最深的根：学校前身是江苏化工学院 / 江苏石油化工学院，石油化工与化工是传统强势；化学工程与技术是省优势学科（第四轮 B-，化学 ESI 全球 1.28‰），安全科学与工程是一级博士点——化工＋安全两个学科同时支撑
  • 不需要企业数据：输入是工艺描述，规则来自国际标准与工程实践
  • 规则密度极高：7×N 矩阵天然就是"可展示的规则表"，正是赛道三要的
  • 和你已有的设计同构：危化品核查、BSL 核查、HAZOP 三者都是"规则表＋条款依据＋覆盖度自查"，文档与代码可复用
  • 答辩抗问：专家问"这条为什么这么分析"，你有推理链和依据；问"会不会漏"，你有矩阵穷举和覆盖度自查

风险与化解

风险化解
"你们有化工背景吗"必须有化工/安全队友主导规则表；没有就不选这个方向
"HAZOP 要专家开会，你凭什么做"定位为教学与预分析工具：帮新手建框架、查遗漏，正式分析仍由持证专家完成
"是不是查表填空"展示推理链、信息缺口识别、覆盖度自查与失败案例修正；查表工具不会追问"泄放去哪了"
责任边界明确"分析辅助，不替代有资质机构的安全评价"

二、备选 A：化工原理衡算核查助手（验证最容易）

定位：输入工艺参数，校核物料平衡、能量平衡、设备能力（泵 NPSH 余量、换热器面积、精馏塔回流比/塔板数）。

  • 最大优势：验证天然——教材习题和设计手册算例都有标准答案，一致率可算、可复现
  • 最大劣势：容易被评成"高级计算器"，创新分低，AI 价值弱
  • 建议：作为 HAZOP 方向的配套模块（"先算对不对，再问危不危险"），不单独成题

三、备选 B：油品性质与调和合规核查

定位：输入调和组分与配比，判断是否满足国 VI 标准（GB 17930 车用汽油、GB 19147 车用柴油），并给出调整建议。

  • 优势：产业味最浓，标准限值明确（硫、烯烃、芳烃、蒸气压、辛烷值/十六烷值），"合规判定"好讲
  • 劣势：调和交互作用复杂（非线性、组分敏感），预测精度难保证；assay 数据难获得；容易变成"算配方"
  • 适合：队里有炼油/油品分析背景，且能拿到组分数据

四、备选 C：油气储运管道泄漏识别

定位：基于质量平衡/负压波原理，从压力流量数据中识别泄漏并定位。

  • 优势：常大油气储运是一流本科专业；工业需求真实
  • 劣势：数据是生死线——真实泄漏数据私有，公开数据集少；没有数据就只能仿真，仿真结论说服力弱（和示功图同一个坑）
  • 结论：除非能找到公开泄漏数据集或老师提供数据，否则不选

六、六句话模板（HAZOP 方向）

  1. 我准备帮助的用户是：化工专业学生、中小企业工艺安全工程师、HAZOP 分析的新手主持人。
  2. 他在新建或改造装置的安全分析场景中，需要解决HAZOP 分析门槛高、易漏偏差、依赖资深专家的问题。
  3. 用户输入工艺流程描述与已有安全设施，作品输出逐条带原因的 HAZOP 工作表、信息缺口清单与整改建议。
  4. 第一版先实现储罐区/换热器/精馏塔三类节点、7 个引导词×4 个参数的分析与覆盖度自查，主要贡献对应赛道三（AI＋跨学科融合创新）。
  5. 我们能获得的资料、工具与规则是IEC 61882、GB/T 21109、化工安全教材案例，以及化工/安全方向老师核定的推理规则。
  6. 我们将用公开 HAZOP 案例回放、老师评审的 10 个节点和缺信息测试检查效果，并如实报告无法判定的情形。
