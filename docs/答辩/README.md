## 三个必答问题（先想好）

1. **这和市面上的跑步 App 有什么区别？** —— 它们给计划不给依据；我们每条结论挂 `rule_id` 和文献。
2. **你验证了什么？** —— 已验证契约、指标复算、异常输入与真实数据联调。回测、对照试验和专家评分按项目计划开展，答辩时以实际结果为准。
3. **真有人用吗？** —— 已用真机跑步记录完成本机联调。答辩用随包的模拟记录复现流程。

## 演示纪律

- 演示只用**预置数据**。用 `python -m src.pipeline --demo --serve` 打开本机页面，断网排练一次。
- 每个数字都能点开看到依据；点不开的就别放。
- 不许念稿式背 PPT，每页只讲一个结论 + 一个证据。
