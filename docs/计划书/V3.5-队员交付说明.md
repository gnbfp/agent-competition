# RunWise AI V3.5 队员交付与计划书编写指引

## 先运行一遍

- 完整解压。Windows 双击 `一键启动-RunWiseAI.bat`。也可用 Python 3.12 运行 `python -m src.pipeline --demo --serve --port 0`，再打开终端打印的网址。
- 双击 `00-双击查看-离线前端.html` 可看匿名样例。CSV 导入、补填与重算需要启动本机服务。
- 首页打开「体验示例」，依次看「七天计划示例」「人工复核示例」「资料不足示例」。上传 `data/sample/running_basic_without_hr.csv` 可演示生成基础报告后，在「七天计划」点「填写缺失资料」。
- 文中路径相对于工程根目录。此包可转发给队员，演示数据为项目样例。

## 写计划书时取用这些材料

| 章节 | 可引用内容 | 对应文件 |
| --- | --- | --- |
| 背景与需求 | 跑量、配速、心率数据怎样转化为可解释的训练决策 | `docs/项目计划书-v0.1.docx`、`docs/项目计划书-v0.1.md` |
| 技术方案 | CSV 导入和校验 → 指标计算 → 风险评估与追问 → 七天草案和自检 → 网页报告 | `README.md`、`接口契约与数据统一方案.md`、`contracts/rules.json` |
| 系统亮点 | 资料不全时生成可用的基础报告；计划按风险和资料完整性暂停；补填后用同一份活动数据重算 | `docs/images/runwise-v35-overview.png`、`docs/images/runwise-v35-plan-supplement.png` |
| 数据与验收 | Garmin、华为、中间格式、无心率记录，以及正常草案、风险待复核、资料待补三种演示 | `data/sample/`、`演示输出/`（队员 ZIP 内） |
| 团队与答辩 | 用现成分工和演示路线对齐章节责任人 | `docs/任务分配-v2.md`、`docs/答辩/现场演示脚本.md` |

旧版计划书中的进度以这次交付为准。V3.5 已支持本机导入、报告和导出、风险复核、补答与量测表单。配置外部模型后可解读报告摘要及回答追问。模型连接需要队员自己的 API 配置，接口测试使用模拟响应。七天计划由本机规则引擎生成，现场展示请把草案、待复核和待补资料三种状态说清楚。演示结果来自样例，可以作为产品功能证据。

## 复验命令

```text
python tools/check_env.py
python contracts/validate_contract.py
python -m unittest discover -s tests
```

本版在 Python 3.12.14 下通过 8 项环境检查、7 份契约样例和 148 项测试。Edge 验证了导入后的报告跳转、补资料入口和重新计算。
