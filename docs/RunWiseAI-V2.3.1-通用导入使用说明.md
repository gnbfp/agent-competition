# RunWise AI V2.3.1 · 通用 CSV 导入与训练报告使用说明

## 为什么有此修正版

上一版 V2.3 误把用户自行上传、用于功能验证的 DeepSeek 模拟数据集设为内置产品场景。这不符合“任意用户自行导入自己数据”的产品定位。此版本**完整移除**这个特定功能，包括前端下拉框、事件监听、后端 `mode=scenario`、随包附送的数据、专用测试、误导性说明，并把离线页面改成项目原有的通用示例。**不会改动训练规则本身。**

## 一、正确打开网页

完整解压压缩包，进入 `agent-competition-ai-preview`，Windows 双击 `一键启动-RunWiseAI.bat`；macOS/Linux 运行 `sh 一键启动-RunWiseAI.sh`。或执行：

```sh
python -m src.pipeline --demo --serve
```

打开 `http://127.0.0.1:8080/live`，不要双击离线 HTML 来尝试上传 CSV。

## 二、手动导入自己的训练数据（正式流程）

1. 左侧进入 **数据导入**，在 **01 选择文件** 拖拽 CSV，或点击区域选择 CSV（2 MB 内）。支持中间格式、Garmin、华为。
2. 点击 **下一步 · 预览数据**，核对列名、前五行和整个 CSV 的日期范围；页面自动建议最后一个有效日期作为截止日，但必须检查它是否符合你的分析意图。
3. 点击 **下一步 · 配置参数**，填写计算截止日（`YYYY-MM-DD`）、静息心率、个人最大心率、TRIMP 生理系数、数据源格式。仅在历史数据确实完整时才填写**历史起始日**。
4. 如需补充睡眠、疼痛、心率基线或背景数据，展开 **更多资料（可选）**，可选择 `measurements.json` 与 `context.json`。它们属于同一运动员时，**匿名 ID 必须保持一致**，否则可能无法正确匹配。
5. 点击 **生成训练报告 ↗**。成功后滚动到概览；等待追问、暂停排课等状态是规则决策的一部分。

## 三、生成图表与完整文字报告

- 点击侧栏 **训练数据** 查看每日 TRIMP，支持 7 天、28 天、全部周期。点击 **↓ 保存当前图表 PNG** 输出 1600 × 900 图像；没有可靠负荷记录时不会伪造曲线。
- 点击侧栏 **训练分析报告** 阅读训练负荷、恢复指标、风险与参考状态、下周计划观察、行动建议及依据。此报告由本地指标与规则模板生成，不需要外部 AI API。
- 点击 **↓ 导出独立 HTML** 保存可双击打开的完整文字报告；点击 **打印 / PDF** 可使用浏览器“保存为 PDF”。
- 风险复核或数据不足时只给出相应解释，不会把缺失数据当正常数值或伪造训练草案。
- 可以选择右上角 **导出报告 → 负荷图 PNG/完整训练分析 HTML/原始 JSON**。

## 四、内置功能演示和用户数据不是一回事

顶部保留项目原本就有的三个按钮：**草案生成演示、人工复核演示、数据不足演示**。它们只演示通用规则逻辑，用项目自带的匿名样例运行。

**你自己准备的 CSV，无论来源或对应哪种情况，都应该通过左侧“数据导入”自行上传，不再预装任何专属测试场景。**

项目根目录 `00-双击查看-离线前端.html` 是匿名样例的**只读外观预览**，无法真实导入或重新计算。正式分析请使用 `/live`。

## 五、与之前版本相比保留的改进

CSV 最新日期建议、输入规则一致性、风险与参考区间分层、六章节完整训练分析报告、计划变化幅度的非阻断提醒、训练执行记录（仅本机）、图表 PNG、报告 HTML/PDF 导出、移动端布局、训练日详情及改期后服务端校验。AI 语言解读仍需自行配置外部 API，非必需。

## 六、限制与隐私

计算服务仅在本机运行；真实训练数据不会随此交付包附带。报告 HTML/JSON 可能包含敏感训练信息，请妥善保存。R19/R20 通过并不意味着训练计划适合每个人，计划调整也不是医学审核。训练执行记录尚未自动回写计算引擎。
