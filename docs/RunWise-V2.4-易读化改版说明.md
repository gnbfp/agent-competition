## 报告文字的基本原则

- **先结论、后数字**。例如“先核对下周训练安排”优先于“R19/R20 已通过”。
- **只解释真实计算的值**。没有睡眠或恢复数据，直接显示信息不足，不编造结论。
- **风险模式不生成可执行计划**。需要人工复核或缺少信息时，明确暂停原因。
- **普通跑者不必理解 TRIMP、ACWR、HRV、VO₂max、R19/R20**。这些词保留在报告底部可展开说明和详细依据中。
- **没有触发风险规则不等于医学安全**。必须保留风险边界；不夸大指标用途。

## 打印修复

除了加深正文，解决了两个影响 PDF 的问题：

1. 旧版 `.panel` 的 `break-inside:avoid` 可能让整个长报告跳到新页，导致第一张纸几乎为空白；现对长报告外壳允许跨页，内部卡片优先保持完整。
2. 旧版淡入动画可能被打印功能截取在低透明度状态；现打印时关闭动画，强制完全不透明。

## 导入数据和导出

完整服务模式 `http://127.0.0.1:8080/live` → 左侧 **上传数据** → 选 CSV → 预览 → 参数 → 可选补充 JSON → **生成训练报告**。查看报告：左侧 **我的训练报告**；查看图：**训练图表** → **保存图表为图片**。

离线模式：双击 `00-双击查看-离线前端.html`，只能查看预设匿名示例。不要把它当成可处理 CSV 的完整前端。
