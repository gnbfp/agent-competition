# RunWise AI V2.8 · 专业分析分层显示

## 本次更新

RunWise 的首页和完整训练报告，默认以跑量、平均配速、跑步时长、跑步次数、平均心率、训练安排和风险建议为主。技术计算不删除，而是按模块分别放进「专业分析」窗口。不同窗口展示不同的真实字段及计算说明，不能计算时显示“未计算”。

- **首页五项核心指标**：每张卡片有自己的「专业分析」按钮。例如配速说明为有效跑步总时长 ÷ 总距离；平均心率只使用有心率的跑步，按其持续时间加权。
- **跑步趋势与训练负荷**：图表标题旁有「专业分析」，用于查看训练负荷 TRIMP、EWMA ACWR、滚动 ACWR、周负荷变化、缺失天数等（仅在有相应数据时展示）。
- **风险提醒与下周计划**：普通界面以简明的风险状态、计划安排为主；技术弹窗查看规则 ID、依据、阈值、检查结果与计划负荷。
- **完整训练报告**：本周期总结、恢复情况、风险评估、下周训练安排、训练建议、缺失资料各有独立的「专业分析」入口。
- **保存完整 HTML 报告**：专业按钮会转换成离线也能展开的 `<details>`，发给别人仍可查看技术内容。打印 PDF 时不强行展开技术细节。
- **手机适配**：技术窗口在小屏幕内滚动，支持关闭按钮和键盘 Esc；不需要打开新浏览器标签页。

### 如何在页面查看专业数据

1. 解压整个 ZIP，Windows 双击 `一键启动-RunWiseAI.bat`，访问 `http://127.0.0.1:8080/live`。
2. 左侧点击「训练概况」：查看公里数、配速、次数、时长、心率；点击某张卡片的「专业分析」可见对应数值与计算方式。
3. 进入「跑步趋势」或「进阶分析」：点击区块右上角「专业分析」。
4. 进入「我的训练报告」：正文是给跑者看的普通语言；点击每个章节旁的「专业分析」阅读该部分的技术指标。
5. 点击「保存完整报告」得到独立 HTML。用浏览器打开后点击「专业分析 · 指标与依据」展开相应内容。

### 如何导入新数据

1. 在正式页面左侧点击「上传数据」。
2. 选择 CSV，点击下一步预览；确认最后有效日期和数据行数。
3. 填写计算参数。可选补充心率、睡眠、身体状态的 JSON 文件，不应人为补造缺失记录。
4. 生成后查看首页、趋势图与训练报告。**缺少心率，跑量和配速仍可用；心率负荷或七天计划可能无法计算或暂缓。**

### 离线版与完整服务的区别

`00-双击查看-离线前端.html`、`RunWiseAI-纯离线交互预览.html` 和单独的预览 HTML 使用固定匿名样例，不支持新 CSV 的完整后端计算。完整分析及历史报告请使用 Python 服务访问 `/live`。

### 计算与安全边界

- 显示值均取自当前报告的 `running`、`metrics`、`risks`、`plan` 等字段，专业窗口不做额外诊断。
- “未计算”不等于零，空缺资料不会用演示值填充。
- 计划通过内部校验不等于适合所有人；对于关键安全资料不足或风险待复核的情况，仍不强行生成具体的七天计划。
