# P5 前端 / 演示

**职责**：只读 `report.json` -> 页面 -> 演示视频与 PPT。

## 起点已经给好了

`index.html` 是一个能跑的最小页面：读 `GET /api/report`，渲染 headline、关键指标、风险列表、下周安排。深蓝主题、无框架、无构建、原生 JS。

```bash
python -m src.pipeline --demo --serve
```

打开终端打印的 `/live` 链接，页面通过同源 `/api/report` 读取这次生成的报告。该服务只监听本机接口，只提供预览页、报告和健康检查。无需先启动模拟后端。

独立调试页面时仍可使用模拟后端。

```bash
# 终端 1：假后端
python contracts/mock_api.py --port 8080
# 终端 2：静态服务
python -m http.server 8000 -d src/p5_web
# 浏览器打开 http://127.0.0.1:8000
```

## 第一件事（可验收，约 1 天）

1. 按上面两条命令把页面跑起来，截图发群（证明 pipeline 通了）
2. 把"风险列表"做成可点击展开「依据原文」——这是本项目区别于普通 App 的展示点
3. 加一个"输入本周数据 -> 生成报告"的加载态（用 mock 的 `--delay 300` 演示）

## 铁律（会被 review 打回）

- **页面不许自己算指标**：ACWR、TRIMP、VO2max 一律从 `report.json` 读，页面上每个数字都要能在 JSON 里找到出处
- 数据缺失显示「数据不足」，不许显示 0
- 网络失败给明确提示，不许白屏（已有 `renderError` 可参考）
- 图表用原生 SVG/Canvas，不引图表库；不引 CDN，**离线必须能跑**（答辩现场可能没网）

## 演示素材

3–5 分钟视频脚本：一屏输入 -> 一屏追问 -> 一屏报告（结论 -> rule_id -> 依据）-> 一屏"计划被打回重排"的日志。
