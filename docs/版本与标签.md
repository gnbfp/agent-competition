# 版本与标签台账

> 每次打 Git 标签都在这里记一行。不懂 Git 的人也能靠这张表找到"哪一版能跑"。
> 打标签的规范见 [团队统一标准与环境要求.md](../团队统一标准与环境要求.md) 第 3.7 节。

## 标签规则速记

| 类型 | 格式 | 例 |
|---|---|---|
| 阶段交付 | `stage-<N>` | `stage-1` |
| 契约变更 | `contract-v<X.Y>` | `contract-v1.1` |
| 仓库/文档快照 | `snap-<主题>-v<X.Y>` | `snap-standards-v1.2` |
| 对外提交版 | `submit-<YYYYMMDD>` | `submit-20261201` |

打完之后推上去：`git push origin --tags`

## 常用查询命令

```powershell
git tag -l                      # 列出所有标签
git show stage-1               # 看某个标签的说明和那次提交
git log --oneline --decorate   # 看提交上挂了哪些标签
git diff stage-1 stage-2       # 两个阶段之间改了什么
```
