# RunWise AI V2.7｜跑者优先版

## 主要变化

- 首页第一屏呈现最近 7 天跑量、平均配速、跑步次数、跑步时长、平均运动心率；分析与训练计划改为第二层。
- 跑步趋势新增「跑量 / 配速 / 心率」三档切换；鼠标移动和键盘方向键查看日期数值；可以保存 PNG。
- 平均配速按**有效跑步记录的累计用时 ÷ 累计公里数**计算，避免错误地简单平均单次配速。
- 平均心率仅根据实际有心率的跑步记录按用时加权，且提示心率覆盖次数，不虚构未记录心率。
- CSV 没有心率仍保留跑步距离和时长并生成报告；心率负荷（TRIMP/ACWR）未知，下周具体训练计划依原安全条件暂停。
- 28 天时间窗口内，无记录日期只有在你明确填写「历史起始日（确认完整时才填）」时才视为零；其余为未知。
- 原有风险规则、训练计划核验、完整训练分析报告、HTML/PDF 导出、动态渐变均保留。

## Windows 操作

1. 解压完整 ZIP，进入 `agent-competition-ai-preview`。
2. 双击 `一键启动-RunWiseAI.bat`。确保已安装 Python 3.12 或更高版本。
3. 浏览器打开 `http://127.0.0.1:8080/live`。
4. 左侧点击「上传数据」→ 选 CSV →「下一步 · 预览数据」→「下一步 · 配置参数」。
5. `计算截止日` 建议选数据最后日期；`历史起始日` 只有确定期间记录无遗漏才填写。
6. 有个人静息心率、最大心率时可以填写并选择计算系数；**没有这些信息可全部留空**，仍会生成基础跑步分析。
7. 点击「生成训练报告」。主页可见跑量、配速、次数、时长、心率；「跑步趋势」切换维度并保存图片；「我的训练报告」导出独立 HTML 或 PDF。

## CSV 最小示例（无心率也可导入）

```csv
date,sport,duration_s,distance_m,avg_hr,max_hr
2026-11-16,run,1800,5000,,
2026-11-18,run,2400,6000,,
2026-11-20,run,3600,10000,,
```

示例含 3 次跑步，21 公里，130 分钟，平均配速约 6 分 11 秒/公里；心率未知。

支持原项目的中间格式、Garmin 和华为 CSV 适配。未提供最低要求的日期、运动类型、时长或距离时仍可能被排除，并在导入质量信息中说明。

## 预览模式

主目录 `00-双击查看-离线前端.html` 供界面预览，使用项目自带**匿名演示数据**，不支持上传；需要真实导入请启动 Python 版。

## 边界

- 本版没有实时设备连接或手表账号同步，需要用户上传导出文件。
- 心率缺失不会凭空估算运动心率；HR 相关负荷和需要其支持的训练计划会继续限制。
- 部分资料不完整时仍会生成已有数据的分析报告；不能可靠判定的指标在报告中标注未知。
- 所有数据默认仅由本地 Python 服务处理，外部 AI 功能仍为可选。
