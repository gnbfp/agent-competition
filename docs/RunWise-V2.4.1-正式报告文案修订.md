# RunWise AI V2.4.1 — 正式报告文案修订

本次只调整界面可见文案、训练报告文字模板及其导出内容；计算、风险规则、输入接口和数据结构不变。

## 改动范围

- 页面主标题改为“个人训练概览”，移除宣传口号和重复的引导性说明。
- 报告栏目使用“训练负荷／恢复情况／风险评估／下周计划／训练建议”；不使用连续问句或口号式标题。
- 取消“现在最该做的事”“看训练量变化，不只看一个数字”“绝不假装已判断”“先打开七天计划”等机械引导文案。
- 报告正文压缩为事实、比较、数据限制和建议；数据不足则标明缺失，风险暂停时不编造训练安排。
- 专业缩写保留在“指标说明（选读）”与规则依据中；必要的限制性提示仍保留。
- HTML 导出和离线预览同样同步了本次修订。

## 使用

完整计算：Python 启动脚本 → http://127.0.0.1:8080/live → 上传数据 → CSV 预览 → 参数 → 生成报告。

离线查看：双击根目录 `00-双击查看-离线前端.html`（仅内置匿名示例）。

## 说明

这是中文产品文案修订，不改变训练分析数值，不增加也不弱化风险检查。详细规则可在原始依据中查询。
