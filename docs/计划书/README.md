## 写之前必须知道的四条

1. **数字只能来自仓库**：负荷、ACWR、VO₂max 的数和阈值，一律引用 `contracts/rules.json` 或 `report.json`，不许估。
2. **引用必须可回查**：文献写「作者 年」、标准写编号、访谈写「XX 老师 2026-XX 访谈」，禁止 AI 编造条目（这是三条红线之一）。
3. **图表都要能指来源**：每张图下面写一句「数据来源：xxx」。
4. **不写没做出来的功能**：v0.1 边界里写的不做项（硬件、医疗诊断、剩余寿命预测）不许出现在方案里。
