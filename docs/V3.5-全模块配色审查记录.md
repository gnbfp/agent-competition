# RunWise AI V3.5 · 全模块配色审查记录

## 结论

本版针对 V3.4 反复出现的青绿、蓝紫、粉紫和黄橙拼接问题，建立单一视觉体系：午夜蓝背景、深蓝灰表面、青蓝强调、少量暖橙风险提醒。动效只出现在首页决策横幅、报告封面与报告重点内容的大面积背景，不应用在导航项、按钮和状态标签上。所有专业数值及风险规则仍由原计算系统产生，没有通过视觉修改更改训练算法。

## 视觉令牌

| 作用 | 色值 | 使用位置 |
|---|---|---|
| 主背景 | `#0D1B27` | 深色主题整页 |
| 基础面板 | `#142838` / `#172D3C` | 内容容器、侧栏衔接 |
| 抬起表面 | `#203849` | 指标卡、折叠内容、上传框 |
| 主文字 | `#F0F7FA` | 页面正文及标题 |
| 次级文字 | `#B6CBD8` | 数值注释、说明 |
| 青蓝强调 | `#84D4DF` | 活跃元素、关键指标、细边线 |
| 主要按钮 | `#126778`，白字 | 实质操作按钮（静态） |
| 风险提醒 | `#D6A269` | 小面积图标和警示边线 |

常见文字组合的目标对比度：白字/`#126778` 大于 6:1；`#F0F7FA`/`#142838` 大于 7:1；次级文字/`#142838` 大于 4.5:1。

## 模块核对清单

| 模块 | 原有视觉问题 | V3.5 处理 |
|---|---|---|
| 左侧导航与顶部栏 | 绿色导航与蓝紫页面不统一 | 使用深蓝灰静态选中态和单一青蓝边线；无导航按钮渐变 |
| 训练概览 | 五张指标卡使用多种强色，横幅紫蓝过饱和 | 五张卡片统一材质；重点横幅限于青蓝同色域缓动；「重点事项」图文同行 |
| 跑步趋势 | 图线偏绿、按钮与卡片色不一致 | 统一图线、网格线、筛选按钮和背景，保留数据类型区分但控制明度 |
| 进阶分析 | 绿色图线混紫蓝底、指标面板层次混乱 | 训练负荷图改用青蓝，指标底色和边框统一，支持专业弹窗 |
| 七天计划 | 紫底配暖黄、按钮多种强调色 | 统一深蓝灰卡片；仅在需要复核时用局部暖橙，计划按钮静态 |
| 风险提醒 | 参考提示和真实警示对比不清 | 相同深色卡片，参考线用青蓝，风险警示线用暖橙，不整卡变色 |
| 我的训练报告 | 封面、总结、建议、数字卡出现多套渐变 | 大块使用统一蓝青缓动渐变；数字卡同一抬起表面；章节折叠用静态层次 |
| 历史报告 | 深紫背景及紫色刷新按钮突兀 | 使用常规蓝灰面板，刷新为静态蓝灰按钮；避免与导入界面割裂 |
| 上传数据 | 步骤条、输入框、上传区颜色不统一 | 统一深蓝灰输入/上传背景，激活步骤为青蓝；去掉提示小字渐变 |
| AI 解读 | 与报告卡材质不一致 | 默认折叠，展开背景与输入控件沿用同一蓝灰体系 |
| 专业分析弹窗 | 与主页面脱节，方法说明及数字卡自用色 | 使用相同主题色、对比度和卡片边框，专业内容不影响主页面可读性 |
| 页脚、打印与移动端 | 浅字、背景断层或打印时动画残影 | 页脚与页面一致；打印强制静态；支持减少动画设置与手动暂停 |

## 工程落地

- **`src/p5_web/theme_unified.css`**：V3.5 唯一的视觉覆盖入口；所有设计令牌及最终配色选择在此维护。
- **`src/p5_web/server_app.html`**：正式服务加载统一主题，首页重点事项结构优化。
- **`src/p5_web/dashboard.js`**：图表线条和坐标对比改为青蓝族，不修改指标计算或判断阈值。
- **`src/report_server.py`**、**`src/p5_web/sw.js`**：提供新主题静态资源，并刷新缓存版本。
- **`00-双击查看-离线前端.html`**：完整内联预览，开箱即用。
- **`tests/test_v35_visual_system.py`**：覆盖新主题加载、全部模块样式入口、打印/减少动画与主要文字对比度。

## 检查边界

测试使用匿名示例报告与前端模板模拟网络响应。当前浏览器测试环境不允许直接访问本机 HTTP 地址，所以没有把这些检查称为真实浏览器与 Python 服务的端到端测试。实际 HTTP 静态资源检查、前端页面测试与自动化代码回归是分别完成的。
