# RunWise AI V2 · 视觉与功能升级交付说明

## 本次目标

把“跑步训练报告展示页”升级为“可解释的训练决策中心”，保留所有 P2 CSV 导入、P3 生理指标、P4 规则/计划引擎与 v2 报告 Schema，增加面向使用者的视觉、交互与便携性体验。

## 特别说明：没有做的事情

1. **没有把 Python 规则引擎改写进浏览器**。完整离线“计算”仍需要本机 Python；独立 HTML 是单份只读报告。
2. **没有开放本机端口给外网或手机**。这样能减少敏感健康数据暴露。手机网页布局可在设备可访问该服务的安全部署环境下使用；要直接在手机查看，当前最方便的是导出的离线 HTML。
3. **没有实现自由编辑强度/跑量或自动生理干预**。只允许整天互换，并通过 R19/R20 + Schema 二次校验；其他风险变化仍需本人或教练人工核实。
4. **AI 解读不是 AI 训练处方**。仍由本地规则引擎生成和限制训练建议。外部 API 费用与服务权限由使用者自行承担。
5. **没有将原始训练数据保存在浏览器的 localStorage、service worker 或云端**。历史仍在本机 `out/pipeline`，PWA 只缓存静态壳。

## 推荐演示顺序

1. 打开 `/live`，先展示报告概览和数据可信度。
2. 点击“草案生成演示”，展示 7 日卡片，打开任一训练日详情。
3. 查看首次候选 321.8 TRIMP 未通过、自动重排后 120.7 TRIMP 通过的规则时间线（数值以实时演示报告为准）。
4. 点击“调整训练日期”选择两个不同日期，展示后端重新核验和历史保存。
5. 切换“人工复核演示”，展示风险门禁阻止排课；切换“数据不足演示”，展示追问与缺失说明。
6. 滚到 CSV 导入向导，上传 `data/sample/demo_activity.csv` 或点击页面“下载演示 CSV”，展示表头预览。
7. 点击“导出报告 → 离线 HTML 报告”，用另一台设备打开，只读展示；切换手机尺寸与深色模式。
