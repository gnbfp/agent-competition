# 运动生理闭环智能体

> 常州大学首届智能体创新大赛 · 赛道三（AI＋跨学科融合创新）
> 把跑步手表的数据翻译成"训练该不该加量、这次心率高是正常还是过度、膝盖疼要不要停"的可解释决策。

一个跑者每周训练完，得到的通常只是"这周跑了 42 公里"这样的数字。本项目做的是另一件事：**先算清负荷、能力和风险，再决定下周怎么跑，并且每条结论都能指回具体依据（rule_id → 依据原文）。**

## 它解决什么

| 现状 | 本项目 |
|---|---|
| 跑步 App 告诉你"下周跑 46 公里" | 告诉你"你现在 ACWR 1.62，已进高危区，下周从 46 降到 30 并取消间歇" |
| 心率高就说"你累了" | 结合配速、心率漂移、静息心率基线判断是疲劳/高温/设备异常 |
| 疼痛了才想起休息 | 主诉疼痛即触发 R15：强制暂停计划，输出就医建议 |
| 数字没有出处 | 每条结论挂 `rule_id`，每条规则挂文献或标准 |

## 仓库结构

```
contracts/   7 份 JSON Schema（指标、计划及报告兼容 v1/v2）、样例、校验器和模拟 API
tools/       环境自检等脚本
src/         p2_ingest（CSV→activity）· p3_metrics（→metrics）· p4_agent（→plan/report）· p5_web（只读 report）
data/        sample（脱敏样例，可进 Git）· raw（原始导出，禁止进 Git）
docs/        文档、AI 使用留痕、答辩材料
tests/       各模块最小测试
```

## 五分钟跑起来

```powershell
python tools/check_env.py                 # 环境自检，必须 8 项全 PASS
python contracts/validate_contract.py     # 契约与样例校验
python contracts/mock_api.py --port 8080  # 起假后端
python -m http.server 8000 -d src/p5_web  # 起前端，浏览器开 http://127.0.0.1:8000
```

要求：Python 3.12.x，**零第三方依赖**（全部用标准库），Git ≥ 2.40。

## 数据与隐私

本项目使用真实跑步记录，**健康数据不进仓库**：`data/raw/` 已被 `.gitignore` 拦截；仓库里只放脱敏样例（匿名 ID + 生理指标）。仓库是公开的，任何一次推送都等于公开发布。
