材料物性仿真辅助智能体（赛道三方案评估与设计）

你提的方向：材料物性仿真辅助智能体。
我的判断：方向对、学科底子最厚，但原话范围太大，必须收敛到一个具体切口，否则会变成"AI 助手聊天"。
推荐切口：不做仿真软件，做仿真的"可信度"——参数怎么定、输入对不对、结果能不能信。

零、先说这个想法对在哪、险在哪

对的地方

  • 学科底子最厚：材料科学与工程是常州大学三个一级博士点之一，材料 ESI 全球前 1%（约 2.18‰），也是省优势学科。这条路你说出去，学校层面是"用本校最强学科做的作品"
  • "仿真"天然带专业规则：参数、判据、收敛条件，全是可写进表格的东西
  • 数据公开：Materials Project、OQMD、AFLOW、NOMAD、COD 都开放，不必求企业

险的地方

"材料物性仿真"是一个学科群，不是一个题目：DFT 第一性原理、分子动力学、CALPHAD 相图、相场、有限元……每一个都是几年的功夫。原话直接当题目，会出现三种死法：

  1. 做成"AI 帮你写 VASP 输入文件"——查表工具，评委会问"AI 在哪"
  2. 做成"AI 解释材料性质"——知识问答，退回赛道一
  3. 想全都做——六周什么都没做完

所以必须收敛。 下面这个切口，是我认为唯一既能保留"仿真"的专业性、又能在六周内做出可验证结果的。

一、切口：不做仿真，做仿真的"可信度"

计算材料学的真实痛点不是不会跑软件，而是跑出来的结果不可信，而且当事人往往不知道：

  • 用 PBE 泛函算带隙，得到 0.6 eV 就写进论文，其实实验值是 1.1 eV 以上（PBE 系统性低估带隙 30–50%）
  • k 点网格随手设 1×1×1，能量根本没收敛
  • 截断能沿用赝势默认值，没做收敛测试
  • 赝势版本混用（同一批计算用了不同 PAW 版本）
  • 算含 Fe/Mn/Ni 的氧化物不开自旋极化，也不加 U
  • 层状材料不做范德华修正，层间距算得离谱
  • 二维材料真空层只留 5 Å，层间相互作用没消掉
  • 缺陷计算超胞太小，掺杂浓度比实际高两个数量级

这批错误全部是教科书级别的、可判定的、有明确依据的（VASP wiki、Quantum ESPRESSO 文档、Materials Project 的方法学说明）。而且"判断结果是否合理"正是赛道三指南的原话。

一句话定位：仿真前帮你定参数、仿真中帮你审输入、仿真后帮你判结果能不能信。

二、主推方案：DFT 仿真方案核查与结果可信度评估

输入 / 输出

内容
输入研究目标（"算 LiFePO4 的带隙" / "算 N 掺杂 TiO₂ 的形成能" / "算层状材料的层间距"）＋ 体系信息（化学式、结构文件 POSCAR/CIF、是否含磁性/强关联元素）＋ 拟用参数或已有输入文件（INCAR + KPOINTS，或 QE input）＋ 已有结果（可选）
输出①参数方案（泛函/截断能/k 点/赝势/色散修正/自旋/超胞/真空层）＋每条依据 ②输入文件问题清单（会导致结果不可信的具体设置）③结果可信度评级（与数据库/文献/实验对照后的判断）④建议的收敛测试清单

三段式流程（这就是 agent 的主循环）

前：方案设计
从研究目标反推参数。目标是带隙 → 不能用 PBE 下结论；目标是形成能 → PBE 可接受但要说明；体系含 Fe/Mn/Ni/O → 必须考虑 +U 或 HSE；层状 → 必须开色散修正。

中：输入审查
解析 INCAR / KPOINTS / POSCAR（都是纯文本，好解析），逐条对照规则表，指出"这条设置会导致什么后果"。

后：结果核验
把算出来的晶格常数、带隙、形成能与 Materials Project 条目、实验值、文献对照，给出"可信 / 存疑 / 不可用"的评级和理由。

怎么验证（这是它能不能赢的核心）

  1. 参数对照：Materials Project 对每个材料都公开了实际使用的泛函、截断能、k 点。拿 20 个材料，比对"你推荐的参数"与"MP 实际用的参数"是否一致、差异是否有理由
  2. 论文方法段回放：找 20 篇论文的 Computational Details 段落，让助手只看研究目标给出参数方案，再由人判断是否与其实际采用的一致、你的方案是否更严谨
  3. 错误注入：造 20 份"埋雷输入"（PBE 算带隙、k 点 1×1×1、ENCUT=200、混赝势、Fe 体系不开自旋），算检出率与误报率
  4. 老师评审：材料学院老师/研究生评 10 个案例，把"他认为该提没提"的补进规则表——修正记录写进答辩材料

这四层里，第 1、3 层能给出具体数字，是答辩最有力的东西。

第一版边界（六周）

  • 只做 DFT（VASP/QE），不碰 MD、相图、相场、有限元
  • 只做周期性晶体，不做分子/表面/界面（可放 v2）
  • 10–15 条规则，覆盖泛函、收敛、赝势、自旋、色散、超胞六类
  • 输入只管 INCAR/KPOINTS/POSCAR 与 QE input 两种格式
  • 不代跑计算，只做方案、审查与核验（这是刻意的边界，也是免责声明）

Agent 形态（三处必须可见）

  1. 主动追问：只知道化学式、不知道是否含磁性元素时，它会问；不知道目标是带隙还是总能量时，它会问——因为参数完全取决于目标
  2. 换路检索：某条规则查不到官方依据时，先查同义表述、再查上位文档，都失败才标"经验做法，非官方强制"
  3. 自校验：报告前统计"15 条规则中已检 N 条、需补充信息 M 条"，覆盖不全就打回

四、三个必须先解决的技术问题

  1. 跑不起 DFT 怎么办？

→ 本来就不跑。这个方案的定位是"让计算可信"，不是"替人算"。若要做 v3，只用 QE + 小体系（Si、NaCl）做收敛演示，纯 CPU 可行。

  1. Materials Project API 怎么用？

→ 注册免费 key，用 mp-api 包查询结构、参数与参考性质；需联网。若答辩环境不能联网，提前把 20 个材料的数据缓存成本地 JSON，演示走离线。

  1. 没有材料背景的队友怎么办？

→ 不建议选这个方向。这套规则表外行写不出来，写出来也是从 VASP wiki 抄，一问就穿。这是它和"室内空气核查"最大的区别。

五、一定会被问的三个问题

  1. "AI 在哪？这不就是查 VASP wiki？"

→ 查表是查不到"我要算这个材料的带隙、但只有 CPU 和一周时间，怎么在精度和成本间取舍"的。AI 做的是：从研究目标反推参数、在约束下做取舍、判断结果能不能信、缺信息时追问。规则引擎保证不漏项，LLM 保证听懂人话。再把"流水线版 vs agent 版"并排演示。

  1. "你们自己算过吗？"

→ 诚实回答：不算，我们做的是让算出来的结果可信。然后展示 QE 收敛测试（如果做了 v3）或 MP 对照实验。

  1. "材料学院认这个吗？"

→ 拿出老师评审记录与规则修正记录——这比任何自我评价有用。

七、六句话模板

  1. 我准备帮助的用户是：刚开始做第一性原理计算的材料/物理方向本科生、研究生新生。
  2. 他在第一次独立设计 DFT 计算方案场景中，需要解决参数怎么定、输入有没有埋雷、算出来的结果能不能信的问题。
  3. 用户输入研究目标、体系结构与拟用参数，作品输出带依据的参数方案、输入问题清单与结果可信度评级。

  5. 我们能获得的资料、工具与规则是VASP wiki、Quantum ESPRESSO 文档、Materials Project 公开数据与参数、pymatgen/ASE，以及材料学院老师核定的判据。
  6. 我们将用20 个材料的 MP 参数对照、20 份埋雷输入文件的检出率、老师评审的 10 个案例检查效果，并如实报告不适用情形。

八、还需要你确认

  1. 队里有没有材料/物理背景、真上手做过 DFT 的同学？（这是这个方向成立的前提，没有就不要选）
  2. 能不能拉到材料学院老师或研究生做规则把关？
  3. 你们有能跑计算的机器或集群账号吗？（决定做 v2 还是 v3）

如果这三点里前两点都是"有"，材料方向很可能是你目前所有选项里专业分最高的一个；如果只有软件队友，我还是建议退回"室内空气核查"或"Hazop（找化工队友）"这类依赖更低的题。
